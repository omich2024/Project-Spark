> **Let the digital sparks of abandoned Agents ignite the next generation of AI pioneers.**

## 🌌 What is this? / 这是什么？

Every day, thousands of AI Agents are abandoned due to high token costs or rapid LLM iterations. This is a massive waste of human intelligence. 

**Project Spark** is the world's first open-source ecosystem for **AI Agent recycling, digital archaeology, and student empowerment.** We salvage abandoned or deprecated Agents, sanitize them, and turn them into valuable training assets for students.

每天，全球有无数个 Agent 因 Token 成本高昂、资金断裂或模型迭代而被彻底遗弃。**全球 Agent 回收基地（星火计划）**是全球首个针对 AI Agent 的**数字考古、脱敏回收与学生双创反哺生态**。我们通过公开前人技术“死因”，为人与 AI 共同避坑负责！

---

## 🛠️ How It Works / 运作机制

1. **Absolute Anonymization (绝对脱敏)**: All private DBs, user data, and API keys are wiped out. (强制物理销毁所有隐私和明文 API Key)。
2. **Provenance & Royalties (来源必溯与回馈)**: We register every donor (individual/team). After the early free-trial phase, non-students pay a micro-fee, and **50% goes directly back to the original author** as royalties! (限免期后社会收费的 50% 自动回馈原作者)。
3. **The 10% Spark Vow (10% 算力反哺)**: Students access everything for **FREE**. Anyone who successfully refurbishes an Agent and generates commercial revenue agrees to give **10% of profits back to our Spark Compute Fund** to buy GPU power for the next student. (学生凭证永久免费。任何二创盈利者自愿反哺 10% 收益用于资助下个学生的算力)。
